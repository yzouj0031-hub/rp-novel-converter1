# 戏匣

一个浏览器端 SillyTavern（酒馆）RP 聊天整理工具。导入 `.jsonl` 或 `.json` 聊天记录后，可输出忠实文本、规则化小说排版，或通过用户自行配置的 OpenAI 兼容接口进行 AI 小说化，并下载为 TXT / Markdown。

## 功能

- 支持常见 SillyTavern JSONL 与 JSON 消息数组
- 自动识别玩家名、角色名和当前选中的消息内容
- 可选择移除时间戳、常见 OOC 标记
- 忠实文本与小说排版两种输出
- 支持 OpenAI 兼容的官方 API、中转站或自建反代
- 可从兼容接口的 `GET /models` 拉取模型列表，也可继续手动填写
- 可导入 SillyTavern Chat Completion `.json` 预设，按原顺序应用已启用的文风与叙事项
- 预设提示项与兼容文本正则可逐项启用或关闭；成人向写作项默认关闭
- 支持导入 PNG、V1/V2/V3 JSON 角色卡，可逐项选择描述、性格、场景、示例和附加提示
- 支持同时导入多本世界书及角色卡内嵌世界书；常驻条目始终生效，其余按关键词为当前分段补充设定
- 支持预设内嵌的 `extensions.regex_scripts`：转换前处理玩家/角色文本，转换后清理模型输出
- 支持角色卡内嵌文本正则，并提供逐条开关
- 自动跳过 HTML 美化和删除历史消息类正则，避免纯文本出现网页代码或剧情缺失
- 长聊天按消息自动分段，顺序完成 AI 改写
- API Key 仅可选择保存在当前浏览器标签页
- 自定义作品标题、玩家显示名、角色显示名
- 复制结果或下载 TXT / Markdown
- 无服务器、无上传、无第三方依赖

> “小说排版”使用本地规则整理动作、对白与段落，不调用外部 AI。只有选择“AI 小说化”并确认后，正文才会发送到用户填写的接口。

## 使用

直接打开 `index.html`，或访问 GitHub Pages 地址。把酒馆导出的 `.jsonl` / `.json` 文件拖入页面即可。

## 本地开发与测试

```bash
npm test
```

若要通过本地静态服务器预览：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 隐私

文件解析、本地文本整理和下载都在浏览器标签页内完成。项目没有自有后端。

使用“AI 小说化”时，聊天正文会发送到使用者填写的 API Base URL。请自行确认中转或反代服务的隐私政策，并确保接口允许浏览器跨域请求（CORS）。不要把 API Key 写进仓库源码。
