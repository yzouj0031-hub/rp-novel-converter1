# 戏匣

一个完全在浏览器本地运行的 SillyTavern（酒馆）RP 聊天整理工具。导入 `.jsonl` 或 `.json` 聊天记录后，可输出忠实文本或规则化小说排版，并下载为 TXT / Markdown。

## 功能

- 支持常见 SillyTavern JSONL 与 JSON 消息数组
- 自动识别玩家名、角色名和当前选中的消息内容
- 可选择移除时间戳、常见 OOC 标记
- 忠实文本与小说排版两种输出
- 自定义作品标题、玩家显示名、角色显示名
- 复制结果或下载 TXT / Markdown
- 无服务器、无上传、无第三方依赖

> “小说排版”使用本地规则整理动作、对白与段落，不调用外部 AI，也不会改写剧情内容。

## 使用

直接打开 `index.html`，或访问 GitHub Pages 地址。把酒馆导出的 `.jsonl` / `.json` 文件拖入页面即可。

## 本地开发与测试

```bash
npm test
```

若要通过本地静态服务器预览：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 隐私

文件解析、文本整理和下载都在浏览器标签页内完成。项目没有后端接口，也不会把聊天记录传到网络。
